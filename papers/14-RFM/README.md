# 14-RFM — Flow Matching on General Geometries

Learning-first reproduction of Chen and Lipman (ICLR 2024). The current slice
fits the **Fire** location distribution on the unit sphere `S^2`.

## Files

- `nbs/spherical.ipynb` — validated closed-form sphere geometry and Eq. 13.
- `nbs/fire_eda.ipynb` — Fire dataset exploration scaffold.
- `src/data.py` — Fire loading, coordinate conversion, and seeded splits.
- `src/geometry.py` — closed-form sphere geometry and conditional flow.
- `src/model.py` — time-conditioned tangent velocity field.
- `src/loss.py` — RCFM regression objective.
- `src/train.py` — training CLI and canonical run persistence.
- `src/evaluate.py` — sampling API and exact held-out NLL CLI.
- `src/plot_samples.py` — observed-versus-generated Fire comparison plot.
- `test_*.py` — AI-owned contracts for data, geometry, model, loss, training,
  sampling, and evaluation.

## Data

- Dataset: Fire locations compiled by Mathieu and Nickel (2020) from EOSDIS.
- Paper size: 12,809 total points.
- Source: the authors' [`data.zip`](https://rtqichen.com/manifold_data/data.zip).
- Expected file: `fire.csv`, with header and rows ordered as latitude, longitude
  in degrees.
- Split: deterministic 80% train, 10% validation, 10% test by default;
  configurable per run.

Data files are local inputs and must not be committed.

## Geometry boundary behavior

- Coincident points have zero logarithmic displacement and conditional velocity.
- `grad_d` returns zero at coincidence as a finite convention for the distance
  singularity.
- Exact antipodes raise `ValueError`: a unique shortest direction does not exist.
  Nearby antipodal points remain supported.

## Run

Run from the repository root with the CLI defaults:

```bash
uv run python papers/14-RFM/src/train.py
```

The defaults are:

- `--epochs 3`
- `--lr 0.0001`
- `--batch-size 1024`
- `--hidden-dim 64`
- `--n-layers 10`
- `--weight-decay 0.0`
- `--device cpu`
- `--data-path papers/14-RFM/data/fire.csv`
- `--seed 42`
- `--train-pct 80`
- `--val-pct 10`
- `--test-pct 10`
- `--runs-base runs`

Training prints a `run_id` and writes
`papers/14-RFM/runs/<run_id>/{config.json,metrics.jsonl,checkpoint.pt}`. Evaluate
that exact run with:

```bash
uv run python papers/14-RFM/src/evaluate.py --run <run_id>
```

Evaluation recreates the seeded split saved in that run's configuration and
reports exact NLL on the held-out test points. It uses batches of 64 by default
because exact Jacobian traces are memory intensive. Override this with
`--batch-size`; use `--data-path` if the CSV has moved since training.

Plot the observed Fire locations beside samples generated by a saved run:

```bash
uv run python papers/14-RFM/src/plot_samples.py \
  --run <run_id> \
  --device mps
```

The plot is saved as `runs/<run_id>/fire-comparison.png`. Sampling defaults to
2,000 points, 1,000 projected Euler steps (matching the authors' visualization
path), and batches of 256; override these with
`--n-samples`, `--steps`, and `--batch-size`.

Suggested first Fire run:

```bash
uv run python papers/14-RFM/src/train.py \
  --epochs 10 \
  --lr 0.0001 \
  --device cpu \
  --seed 42
```

For a bounded author-scale speed calibration on Modal:

```bash
uv run modal run papers/14-RFM/modal_train.py \
  --gpu A100-40GB \
  --cpu 8 \
  --memory 32768 \
  --epochs 500 \
  --batch-size 8192 \
  --hidden-dim 2048 \
  --n-layers 10 \
  --lr 0.0005 \
  --weight-decay 0.01
```

This default calibration performs approximately 1,000 optimizer updates and
reports elapsed time, updates per second, final training/validation loss, and
the held-out test NLL from the same checkpoint. Override the evaluation
settings with `--eval-batch-size`, `--rtol`, and `--atol`. It is a bounded
calibration, not the paper's full million-update training run.

The Modal job uses the persistent Volume `rfm-fire-results` and writes the
checkpoint, run metadata, and final result to `calibration/`. Retrieve the final
JSON after completion with:

```bash
uv run modal volume get rfm-fire-results \
  calibration/latest_result.json rfm-fire-result.json
```

Full paper tests:

```bash
uv run pytest papers/14-RFM/ -q
```

Open `papers/14-RFM/nbs/fire_eda.ipynb` for exploration after downloading the
CSV.

## Hyperparameters

The training CLI accepts `--epochs`, `--lr`, `--batch-size`, `--weight-decay`, `--hidden-dim`, `--n-layers`,
`--device`, `--data-path`, `--seed`, `--train-pct`, `--val-pct`, `--test-pct`,
and `--runs-base`. The three percentages are stored as percentage points in the
run configuration; they must be finite, non-negative, and sum to 100.
Evaluation accepts `--run`, `--batch-size` (default 64), `--device` (default
CPU), `--rtol` and `--atol` (both default `1e-7`), `--data-path`, and
`--runs-base`.

## Results

| Fire test NLL (lower is better) | Value |
|---|---:|
| Uniform-sphere baseline | +2.531 |
| Locally confirmed reproduction | −0.7004 |
| Paper, five-run mean and variation | −1.86 ± 0.11 |

The local evaluation on 2026-10-13 confirms NLL −0.7004 on all 1,282 held-out
points, using the saved checkpoint and current evaluator. This improves on the
uniform baseline but does not match the paper. The [evaluation record](results/local-evaluation-20261013.json)
includes checkpoint/data hashes, split, solver, tolerances, and evaluator revision.
The CLI reports four decimal places. [Artifact provenance](results/README.md)
distinguishes this result from the older Modal calibration evaluation.

![Observed Fire locations and generated samples](results/fire-comparison.png)

The saved plot comes from run `20260818-103835`, seed 42. It compares all 12,809
observed locations with 2,000 generated samples as a qualitative visualization;
the observed panel includes training points. The run configuration records
5,000 epochs, width 2,048, 10 hidden layers, batch size 8,192, learning rate
0.0005, and weight decay 0.01. The historical configuration does not record a
Git revision. The plot alone does not establish the NLL above.

## Completion

The three-day Fire experiment is complete when one reproducible run generates
unit-sphere samples that visibly recover the Fire distribution and outperform
the uniform-sphere baseline under the chosen evaluation.

Paper reference: RFM with geodesics reports test NLL **-1.86 +/- 0.11** over five
runs. Matching that number is not the completion gate for the M1 reproduction.
